# LeadMap KZ

Радар потенциальных клиентов из 2ГИС по Кызылорде: компании без сайта или с потенциалом внедрения CRM.

## Автономная версия без входа

Откройте файл `LeadMap-local.html` двойным кликом. Он работает локально, без сервера, установки и входа через ChatGPT.

В автономной версии доступны:

- фильтрация и поиск по базе лидов;
- прямые ссылки на точные карточки компаний в 2ГИС;
- переход в WhatsApp с готовым персонализированным сообщением;
- сохранение лидов в браузере;
- экспорт выбранной базы в CSV.

## Версия для разработки

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```

Контактные данные взяты из открытых карточек компаний. Перед обращением проверьте их актуальность и соблюдайте правила площадок и местное законодательство.
